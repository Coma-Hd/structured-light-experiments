## 1. 今日完成的优化

### 1.1 关键帧交互式 ROI

旧流程需要反复手改 `config.yaml -> laser.image_roi`。现在增加：

```text
扫描序列
→ 均匀选择 3～5 张关键帧
→ 每张用鼠标画矩形 ROI
→ 保存 roi_keyframes.json
→ 按 distance_mm 为每一帧插值 ROI
→ 只在该帧 ROI 内提取激光
```

中间帧不是使用固定平均框，而是分别对以下四条边按导轨行程线性插值：

- `x_min`
- `x_max`
- `y_min`
- `y_max`

因此关键帧之间允许框的位置和大小不同，中间框会连续移动和缩放。

### 1.3 重建链路改造

- `extract_laser_centers()` 支持单帧 `image_roi_override`。

## 3. 正方体与球体的差异

ROI 只负责选定“在哪个图像区域提激光”，不会自动保证正方体结果一定是正方形。

### 正方体单面

要得到完整方形平面，还必须满足：

1. 所有关键帧框选同一个面，不进入邻面。
2. 激光完整扫过该面的左右边界。
3. `positions.csv` 位移准确。
4. 关闭球面 trim：

```yaml
postprocess:
  surface_trim_k: 0
```

5. 开启平面提取：

```yaml
pipeline:
  extract_largest_plane: true
```

最终用 `largest_face_upright.ply/obj` 测量长宽和检查平面度。

### 球体/不规则曲面

```yaml
postprocess:
  surface_trim_k: 2.5

pipeline:
  extract_largest_plane: false
```

主看：

- `cloud_clean.ply`
- `surface_bpa_smooth.obj`
- `cloud_clean_aligned.ply`

## 4. 点云破缺问题复盘

当前点云呈规则线阵，但存在：

- 相邻激光切片之间不够密
- 单条激光线内部有漏点
- 反光、暗面或 ROI 边缘产生断线
- 顶部/边缘有不连续区域

这些问题不能全部依靠网格“强行封洞”解决，因为不规则物体可能真实存在：

- 孔洞
- 沟槽
- 深度突变
- 遮挡边界

Poisson 会倾向封洞，只适合作为平滑预览，不应作为保真几何的唯一结果。

## 5. 导轨步距结论

把步距从 1 mm 直接改为 0.1 mm：

- 扫描方向切片会密约 10 倍
- 94 张会增加到约 931 张
- 单条激光线内部的点间距不会改善
- 反光/漏检造成的断线不会自动恢复

当前配置：

```yaml
postprocess:
  voxel_size: 0.0005  # 0.5 mm
```

若使用 0.1 mm 步距，大量点会被 0.5 mm 体素合并，收益有限。

正式建议：

1. 默认先使用 **0.5 mm** 步距。
2. 仍不够密时试 **0.25 mm**。
3. 只有机械重复精度、标定误差和曝光都足够时才测试 0.1 mm。
4. 0.1 mm 扫描需将 `voxel_size` 同步降到约 0.15～0.2 mm。

## 6. 正式方法的后续阶段（尚未实现）

以下方案已经确定为保真重建方向，但当前代码尚未实现，不能按现有命令直接使用：

### 6.1 四点多边形 ROI

矩形 ROI 将升级为：

```text
每张关键帧点选四个顶点
→ 保存四边形
→ 中间帧逐顶点按行程插值
→ 仅在多边形掩膜内提取激光
```

它适合斜视正方体，可减少矩形同时包含邻面的情况。

### 6.2 保留扫描拓扑的受约束三角化

重建时保留：

- 帧号
- `distance_mm`
- 激光线上的点序号
- 激光响应/置信度

只连接相邻扫描单元，并检查：

- 三维边长
- 深度跳变
- 法向夹角
- 点的置信度

只填补被连续曲面完全包围的小洞；大洞、真实孔洞和遮挡边界保持开放。

在该功能完成前：

- `cloud_clean.ply` 是保真判断主结果。
- BPA 仅作为近似网格。
- Poisson 仅作为平滑展示。
