# 机械臂末端手持扫描（未上电手动拖动）

相机与线激光固连在机械臂末端法兰上；物体放在固定的 ChArUco 板上。  
机械臂**暂时不上电**，由人手动拖动末端到不同视角，逐姿态拍摄线激光条纹图。

与导轨 / 转台的核心差异：**没有行程或转角编码器**。本目录用**每帧可见的标定板**估计相机相对板的 6DoF 位姿，再把激光三角测量点变换到板坐标系融合。

---

## 可行性结论

**可行。** 现有重建管线已支持：

```text
pose_source: charuco
charuco_tracking.mode: per_frame
```

每帧流程：

1. 检测板上 ChArUco 角点 → PnP 得板→相机位姿
2. 提取线激光中心 → 与激光平面求交得相机系 3D 点
3. 用该帧位姿把点变到**板坐标系**并融合

不需要知道两帧之间怎么移动、移了多少；只要**每帧都能看到足够多的板角点**，相对运动就隐含在位姿差里。


| 项目    | 导轨 / 转台         | 本方案（机械臂未上电）        |
| ----- | --------------- | ------------------ |
| 运动已知量 | 行程 mm / 转角 °    | 无                  |
| 位姿来源  | 编码器 + 轴标定，或板轨拟合 | **逐帧 ChArUco PnP** |
| 相机-激光 | 相对固定            | 相对固定（装在末端）         |
| 物体与板  | 固定              | 固定                 |
| 尺度    | 编码器或板           | **板方格尺寸**          |




### 前提条件（必须满足）

1. **相机与线激光刚性固连**，扫描过程中不得相对松动。
2. **内参 + 激光平面**必须在本安装状态下标定（分辨率、曝光、增益与扫描一致）。标定过程中末端应锁死，不要晃动。
3. **物体与标定板相对固定**；只移动机械臂末端。
4. **每张可用图中板必须可见**（允许部分遮挡，但角点数需 ≥ `gating.min_charuco_corners`，默认 8）。
5. 手动拖动时：**移动 → 停稳 → 再拍**，避免运动模糊。



### 主要风险与限制

- 板被物体或手挡住 → 该帧无法求位姿，直接丢弃。  
- 逐帧 PnP 比导轨 `rail_fit` 更噪，点云条纹可能略抖；后续机械臂上电后可用 FK 平滑。  
- 无行程/转角时，关键帧 ROI 改为按 **扫描帧序号** `frame_index` 插值（见 `2_draw_check.ps1`）。  
- 姿态覆盖太窄（几乎只在一个位置拍）→ 点云稀疏；检查脚本要求光心包络跨度 ≥ 15 mm。

```powershell
  --config ceshi/上机械臂/arm_scan.yaml `
  --out ceshi/上机械臂/data/calibration/intrinsic `
  --mode shot `
  --cam 1 `
  --width 800 `
  --height 600 `

  --gain 7

  --config ceshi/上机械臂/arm_scan.yaml `

  --out ceshi/上机械臂/calibration/camera_intrinsic.yaml
```

验收：重投影误差 **< 1 px**。

再开激光，保持同一曝光增益与安装，标定激光平面：

```powershell
.\.venv\Scripts\python.exe scripts/capture.py `
```

## 1. 扫描采集



### A. 停稳单拍（最稳）

拖到一个姿态 → 停稳 → 空格拍一张 → 再拖：

```powershell
powershell -ExecutionPolicy Bypass -File .\ceshi\上机械臂\0_capture.ps1 `
  -Cam 1 -Width 800 -Height 600 -Exposure -4 -Gain 10 -ClearOutput
```



### B. 平稳拖动自动连拍（推荐用于扫面）

慢速平滑拖动末端时自动按时间间隔存图；默认**只有标定板角点足够且不够糊**才保存：

```powershell
powershell -ExecutionPolicy Bypass -File .\ceshi\上机械臂\0_capture_continuous.ps1 `
  -Cam 1 -Width 800 -Height 600 -Exposure -7 -Gain 10 `
  -IntervalMs 150 -Countdown 3 -ClearOutput
```

操作：

1. 预览中确认板可见（角点数够、红点在格线交点）
2. 需要时可先调相机（与 `capture.py` 相同）：
  `a` 自动曝光 · `e/d` 曝光 · `r/f` 增益 · `b/v` 亮度 · `l` 激光叠加 · `c` 板检测
3. 按 **空格** → 倒计时 3 秒 → 开始连拍
4. **慢速、平稳**拖动机械臂，保持板和物体激光同时入画
5. 再按 **空格** 停止，或 `Q` 退出

常用参数：


| 参数                    | 默认      | 含义                       |
| --------------------- | ------- | ------------------------ |
| `-Exposure` / `-Gain` | -4 / 10 | 初始手动曝光与增益                |
| `-Brightness`         | 不设      | 初始亮度（≥0 才传入）             |
| `-AutoExposure`       | 关       | 启动时开自动曝光                 |
| `-IntervalMs`         | 150     | 存图间隔（ms），约 4 Hz          |
| `-Countdown`          | 3       | 空格后倒计时再开拍                |
| `-MinSharpness`       | 20      | 模糊过滤；过严可调到 `10` 或 `0` 关闭 |
| `-AllowNoBoard`       | 关       | 加上后不要求板可见（一般不要开）         |
| `-MaxFrames`          | 0       | 最多张数，0=不限                |
| `-ClearOutput`        | 关       | 开拍前清空旧 `img_*.png`       |


采集要点：

- 每张图尽量同时看到：**物体上的激光线** + **足够的标定板**  
- 拖太快会因模糊被跳过；太快且板出画则几乎存不下图  
- 多距离、多倾角覆盖物体表面

## 3. 关键帧 ROI + 激光抽检（必做）

机械臂模式没有 `positions.csv` / `angles.csv`，因此 ROI **不按行程或转角插值**，改为按扫描目录排序后的 `**frame_index`** 在关键帧之间线性插值，作用与导轨五关键帧 ROI 相同：只在物体激光附近提中心，抑制板面/背景杂光。

```powershell
powershell -ExecutionPolicy Bypass -File .\ceshi\上机械臂\2_draw_check.ps1
```

操作：

1. 脚本均匀选出约 5 张关键帧
2. 在每张上**拖拽矩形框住物体上的激光线**（尽量不要框进标定板）
3. `ENTER` 确认下一张；`r` 重画；`s` 跳过
4. 自动对若干中间帧写出带插值 ROI 的激光检查图到 `work/laser_check/`

验收：

- 检查图里红点应贴着物体激光核心  
- 插值 ROI 应覆盖整段物体激光，且尽量避开板面  
- **激光尚未扫入 ROI 时不应出现红点**（由 `laser.roi_laser_gate` 门控；检查图可几乎无红点）  
- 若某帧 ROI 明显偏了，重新跑本脚本（或 `-ReuseRoi` 仅重出检查图）

已有 ROI、只想复检时：

```powershell
powershell -ExecutionPolicy Bypass -File .\ceshi\上机械臂\2_draw_check.ps1 -ReuseRoi
```
