## 一、系统原理与数据流

相机与线激光**刚性固定**，激光形成固定光平面。每帧只得到「激光平面 ∩ 物体表面」的一条轮廓。无导轨，用 ChArUco 位姿把每帧点统一到**板坐标系**后累积。

```text
物体+板一起移动
  → 每帧: ChArUco 位姿 + 激光中心提取
  → 射线 ∩ 激光平面 → 相机系 3D 点
  → 变换到板坐标系并累积 → cloud.ply
  → ROI/滤波 → cloud_clean.ply
  → 网格 → OBJ
```

**坐标约定**：板面恒在 `Z≈0`；`Z` 是垂直标定板的深度，不是普通查看器的“竖直向上”。板前物体通常在 `Z<0`。

**两种业务目标**：

| 模式 | 单次目标 | 主结果 |
|------|----------|--------|
| 平面（正方体） | 最大有效物体平面 | `largest_face.ply/obj` |
| 曲面（球体） | 局部曲面片 | `cloud_clean.ply` + `surface_bpa_smooth.obj` |

完整正方体/球体需要多姿态；单次只能得到一个面或一块曲面片。

4. PowerShell 脚本提示用英文 ASCII（PS 5.1 读 UTF-8 中文会乱码）。

## 四、调试方法论（最重要）

分段定位，不要先看 OBJ：

```text
实物 → 采集图 → debug_laser 红线 → cloud.ply → cloud_clean.ply → OBJ
```

口诀：

1. 红线不对，后面全错。
2. **关 ROI 时，板面应集中在 Z≈0** → 判断激光平面是否有效。
3. 先看点云，再调网格。
4. 窄 ROI 短中段策略下，弱曲率可能正常；先查 `cloud_clean` 是否已平。

## 五、踩坑与修正全记录

### 坑 1：两次采集图片混用
- **现象**：点云乱，像两次扫描叠加。
- **原因**：重建读整个 scan 目录。
- **修正**：每次清空旧图；曲面采集脚本在目录非空时报错。

### 坑 2：OBJ 变成标定板
- **现象**：`mesh_planes` 是大板面。
- **原因**：板面点最多；DBSCAN `keep-clusters=1` 只留最大簇=板面。
- **修正**：ROI 切板面；已清理点云转 OBJ 用 `--no-dbscan`；平面主结果改用 `extract_largest_plane`。

### 坑 3：ROI 的 z 太窄，切掉一个面
- **修正**：用 `inspect_cloud` 看直方图，阈值切在板面层与物体层之间。

### 坑 4：`*_view` 方向反而不对
- **结论**：融合/测量用未转换文件；view 仅辅助显示。

### 坑 5：二进制 PLY 读失败
- **原因**：Open3D 写出二进制，`read_ply_xyz` 只支持 ASCII。
- **修正**：`inspect_cloud` / `reorient_for_view` 优先用 Open3D 读。

### 坑 6（核心）：顶面/球面上半段激光提不到
- **原因 A**：`row` 每行只取最强点，标定板抢走物体点。
- **原因 B**：`steger` 下原 `min_intensity` 不生效。
- **原因 C**：`B-max(R,G)` 压制紫白激光。
- **修正**：`score_mode: blue_minus_green`；`components` 或多段保留；`image_roi` 限制提取区域。

### 坑 7：改成“单次只取一个平面”
- **做法**：`extract_largest_plane.py`；正方体分面扫，后续再融合。

### 坑 8：球面不能用最大平面
- **原因**：会把曲面压成切平面。
- **修正**：独立 `surface_config` + 曲面流程，保留曲面点云。

### 坑 9：连通线把 ArUco 边缘当激光
- **修正**：提高阈值、连通块过滤；或 `image_roi` 排除板上半部。

### 坑 10：`keep_largest=1` 删掉球面线
- **原因**：激光被球断开，最大块是板线段。
- **修正**：`keep_largest≥2`，或改用 image_roi 后不必靠排名。

### 坑 11：PowerShell 中文脚本语法错误
- **修正**：`.ps1` 提示改为英文 ASCII。

### 坑 12：改了 ceshi 配置但调试工具无效
- **原因**：`debug_laser`/`capture` 默认读根目录配置。
- **修正**：统一传 `--config`。

### 坑 13：球面点云成“斜坡”，疑似激光平面坏了
- **过程**：抬平台后斜坡明显；重标激光平面后 `[a,b,c,d]` 几乎不变，RMS≈0.395mm。
- **验证**：关 `image_roi`+`roi` 后点数大增；Z 直方图最密箱覆盖 `Z≈0`。
- **结论**：**激光平面基本正常**。斜坡主要来自桌面（板坐标系里斜着的平面）+ 掠射噪点 + 板面混扫。
- **修正**：开回三维 ROI，切掉板面与远噪，只留物体附近。

### 坑 14：红线锯齿 → 点云棱角
- **修正**：`steger` + `score_blur` + `smooth_window`；窄 `image_roi` 只取中间平滑段。

### 坑 15：窄 ROI 导致竖条纹/皱锡纸网格
- **原因**：每帧只截极短激光段，累积成平行扫描条；BPA 忠实保留噪声。
- **策略取舍（当前采用）**：宁可短中段换红线稳定；完整强曲率靠多姿态/多短段拼接。
- **网格**：`finish_surface_mesh.py`；BPA 平滑 vs Poisson 裁填。

### 坑 16：过度平滑把球面压成“略弯平面”
- **原因**：`smooth-iters` / `bpa-radius-scale` / `mesh-smooth` 过大。
- **更关键**：若 `cloud_clean` 本身 Z 跨度已经很小，根因是短中段采样曲率不足，不是网格。
- **修正**：先查 `cloud_clean` 侧视图；网格用温和参数保曲率。

### 坑 17：`finish_surface_mesh` Poisson 裁剪报错
- **原因**：`TriangleMesh` 无 `compute_point_cloud_distance`。
- **修正**：先把顶点建成 PointCloud 再算距离。

## 六、平面与曲面最终策略

### 平面（正方体）
- 单次目标：最大有效平面
- 主结果：`ceshi/output/largest_face.*`
- 完整立方体：多面分别扫，再融合（共板坐标系可用 `5_merge_views.py --method charuco`）

### 曲面（球体）
- 单次目标：局部曲面片（不是完整球）
- 激光策略：窄 `image_roi` 取中间最平滑短段
- 主结果：`cloud_clean.ply` + `surface_bpa_smooth.obj`
- Poisson：更平滑但易补面 → 用 `surface_poisson_cropped.obj`
- 弱曲率：短中段固有限制；要更大曲率需换姿态或拼多条短段

## 七、标准执行流程（摘要）

详细命令与输出表见 `ceshi/README.md`。此处只列结构。

### 平面三大步
1. `capture.py --config ceshi/config.yaml --out ceshi/scan ...`
2. `debug_laser.py --config ceshi/config.yaml ...`
3. `ceshi/run_pipeline.ps1`  
   （内部：`3_reconstruct` → `4_postprocess` → `inspect` → `ply_to_obj` → `extract_largest_plane` → `reorient_for_view`）

### 曲面三大步
1. `ceshi/surface_1_capture.ps1 -Camera 0`
2. `ceshi/surface_2_check_laser.ps1`（必须先通过）
3. `ceshi/surface_3_reconstruct.ps1`  
   （内部：重建/后处理/inspect/`ply_to_obj`/`finish_surface_mesh`）

仅调网格平滑（不必重采）：

```powershell
python scripts/finish_surface_mesh.py --in ceshi/surface/output/cloud_clean.ply --out-dir ceshi/surface/output --smooth-iters 2 --bpa-radius-scale 1.6 --mesh-smooth 6
```

## 八、配置参数速查

### `laser`（提取）
| 参数 | 说明 |
|------|------|
| `method` | `centroid` / `steger` / `components` |
| `score_mode` | `blue_minus_max` / `blue_minus_green` / `blue_minus_mean` |
| `score_threshold` | 响应阈值 |
| `min_intensity` | 注意：经典 `steger` 路径下原先不参与计算 |
| `scan_axis` | 近竖直线用 `row` |
| `image_roi` | 图像归一化 ROI，先限制再提取 |
| `smooth_window` | 沿激光线中值平滑，减左右抖动 |
| `score_blur_sigma` | 响应图预模糊 |

### `roi`（点云裁剪，板坐标系，米）
- 板面 `Z≈0`；板前物体常 `Z<0`
- 阈值用 `inspect_cloud` 直方图定，不要猜

### 红线
- 三者分辨率一致（800×600）
- 相机-激光相对位姿变了 → 重标激光平面
- 换镜头/对焦/分辨率 → 内参也重标

## 九、验收指标

| 阶段 | 指标 |
|------|------|
| 内参 | 重投影误差 < 1px（理想 <0.5） |
| 激光平面 | `fit_rms_m` ≈ 0.1~0.5mm；关 ROI 时板面峰在 Z≈0 |
| 激光提取 | 红点覆盖目标表面，锯齿可接受 |
| 点云 | 板面可切净；物体轮廓可辨 |
| 平面主结果 | `largest_face` 对应目标面 |
| 曲面主结果 | `cloud_clean` 为曲面片；`bpa_smooth` 开放不过度压平 |
| 最终 | 已知尺寸误差可接受 |
