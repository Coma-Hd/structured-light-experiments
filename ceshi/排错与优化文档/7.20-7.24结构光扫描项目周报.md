# 7月20日至7月24日结构光扫描项目复盘周报

## 一、本周工作概述

本周工作围绕“电动导轨连续扫描、固定 ChArUco 板多面重建、曲面扫描及绝对精度验证”展开。技术路线从早期依赖手工导轨方向、正方体几何约束和 ICP 拼接，逐步调整为：

```text
固定 ChArUco 板建立公共坐标系
→ 自动拟合导轨轨迹和实际位移比例
→ 统一激光中心提取与激光平面标定参数
→ 各次扫描直接重建到板坐标系
→ 重叠区域只用于误差检查，不依赖 ICP 掩盖标定误差
→ 使用标准件验证重复性、局部表面误差和绝对尺寸准确度
```

本周完成了电机连续采集流程升级、两面点云拼接验证、四面点云误差定位、曲面扫描独立工作区建设、Windows 环境兼容修复以及标准半球重复性实验。旧标定下半球平均偏小约 `5.65 mm`；7月24日下午重新优化标定和激光识别后，当前单次半球拟合直径为 `96.386 mm`，相对 `98.900 mm` 偏小 `2.514 mm`。系统已具备连续曲面重建和固定精度报告能力，主要问题已从“流程能否运行”转向“如何把重复性稳定到 0.1 mm，并继续消除激光深度的绝对尺度误差”。

## 二、本周主要进展

### 1. 完成电机连续扫描与固定板轨迹拟合

将原有“手动导轨、手填 `rail.axis`、依赖正方体直角约束”的流程升级为电机连续扫描。相机与线激光器刚性连接并随导轨运动，物体与 ChArUco 板保持固定。

程序通过每帧 ChArUco 位姿计算相机光心在板坐标系中的位置，并鲁棒拟合直线轨迹，自动得到：

- 导轨在板坐标系中的真实运动方向。
- 实际位移与名义位移的比例。
- 平滑后的逐帧相机位置和平均姿态。
- 各面点云到公共板坐标系的直接变换。

Face1、Face2 轨迹均通过质量验收：

```text
Face1：272/272 帧有效，行程 141.54 mm，轨迹 RMS 0.865 mm
Face2：251/251 帧有效，行程 125.02 mm，轨迹 RMS 0.713 mm
```

已验证单次扫描可恢复接近直角的双平面结构，Face1 两主平面夹角为 `89.62°`。

### 2. 完成 Face1 与 Face2 两面拼接验证

通过共享棱锚点、双平面候选初值和多尺度 ICP，Face1 与 Face2 拼接达到：

```text
fitness：0.9706
RMSE：1.348 mm
锚点 RMSE：5.330 mm
ICP 相对初值旋转：1.019°
accepted：true
```

该结果验证了连续扫描、固定板轨迹拟合和受约束小范围拼接的可行性。同时也明确：ICP 只适合修正具有真实重叠时的小范围刚体误差，不能替代激光平面标定。

### 3. 修复 ChArUco 共面位姿错误

早期虽然所有图像均检测到足够角点，但 ChArUco 有效位姿为 0。排查发现，共面标定板使用 `solvePnPRansac` 时容易选中错误平面分支，导致 `15～62 px` 的重投影误差。

改为使用全部检测点执行 `SOLVEPNP_ITERATIVE` 后：

```text
单帧重投影误差约 0.885～1.097 px
平均约 0.984 px
Face1、Face2 全部位姿通过
```

这项修复消除了共面 PnP 错解对导轨轨迹和公共坐标变换的影响。

### 4. 修复激光平面标定中的数据污染

本周确认了两类关键标定问题：

1. 旧流程先在整幅图像提取激光，再将板外激光与无限延伸的标定板平面求交，地面和背景激光被错误当作板面点。
2. 激光标定目录混入不同刚性状态下的两批图像，旧程序只检查 RANSAC RMS，没有检查总内点率。

优化后增加：

- ChArUco 板凸包掩膜，只保留实体板内激光。
- 单帧 ChArUco 重投影误差检查。
- 激光平面总内点率门限。
- 按文件名前缀筛选同一标定批次。
- 每个板姿态近似等权采样。

板面激光的深度误差由旧平面的约 `106 mm` 降至约 `8 mm`，但仍未达到计量要求，因此后续不能只依据平面拟合 RMS 判断标定有效。

### 5. 优化激光中心提取和反光抑制

在四面扫描图像中发现，过曝后的真实激光核心呈白色或白紫色，而旧 `blue_minus_green` 模式偏向外围纯蓝色光晕。约 `3.5 px` 的中心偏差可造成约 `6.82 mm` 的三维变化，其中深度变化约 `5.86 mm`。

本周新增并统一 `blue_weighted_intensity` 响应，使激光中心到白紫核心的中位偏差由约 `3 px` 降至约 `1 px`。同时明确：

```text
激光平面标定与正式扫描必须使用相同的
分辨率、曝光、增益、响应模式、门限和 Steger 参数。
```

针对金属曲面反光，将采集参数由：

```text
Exposure = -3，Gain = 20
```

调整为：

```text
Exposure = -5，Gain = 1
```

反光光晕、连续假激光线和尖刺明显减少。进一步增加激光线宽、饱和宽度、双峰和中心连续性质量门控，只删除不可信中心，不平滑或移动保留的亚像素坐标。

### 6. 完成四面点云误差诊断并调整技术路线

四面点云在同一板坐标系下仍存在明显分离。重新检查坐标变换后，数值往返误差约为 `1e-16 m`，未发现转置、逆变换或单位错误。

自动几何分析结果为：

```text
单面平面拟合 RMS：约 0.67～0.82 mm
相邻面夹角：约 85.4～88.3°
接缝 XY 间隙：约 10.95～16.37 mm
各面径向外扩：约 7.15～11.78 mm
```

四个面呈共同向外扩张，更符合激光三角测量深度系统误差，而不是某一个面的随机位姿错误。

同时确认当前四份点云缺少真正的法向一致重叠区域，在 `25 mm` 内的相邻双向覆盖率仅约 `12.16%～16.61%`，在 `10 mm` 内几乎没有可靠对应。普通 ICP 和 FPFH/RANSAC 会因大平面对称性产生错误的大角度旋转和数百毫米平移，因此不能用于正式修正。

本周据此将正式路线调整为：

```text
先保证内参、激光平面和位姿的绝对准确
→ 每帧直接转换到同一板坐标系
→ 直接融合
→ 重叠区域只用于误差检查和拒绝
```

### 7. 建立独立曲面扫描工作区

为避免四面扫描、标定文件、ROI 和输出路径交叉引用，建立独立的 `ceshi/曲面/` 工作区，集中管理：

- 曲面专用配置。
- 内参与激光平面标定数据。
- 正式扫描图像和位置记录。
- ROI、检查图、点云和验证报告。

自由曲面流程关闭最大平面提取、双平面清理和自动补面，避免真实凸起、凹陷和边缘被平面专用逻辑误删。

当前 Steger 实现仍为每行保留一个最强响应，适用于连续单值凸曲面；对于深凹槽、孔洞或同一行多段激光的复杂曲面，后续需要升级为多分支候选和跨行、跨帧连续跟踪。

## 三、本周关键问题及原因判断

### 1. 绝对尺寸稳定偏小

首轮半球直径稳定偏小约 `5.65 mm`；本轮新标定和识别算法将单次偏差改善到约 `-2.51 mm`，但尚未消除。四面点云又呈共同外扩，两类现象仍共同指向激光深度系统误差。

当前原因优先级为：

1. 当前内参重投影误差约 `0.956 px`、激光平面 RMS 约 `0.414 mm`，仍高于 0.1 mm 级计量目标所需质量。
2. 无显像剂时，半球材质和入射角可能引起激光中心相对标定板的系统偏移。
3. 曲面允许最大 `50 px` 的宽响应进入 Steger 定位，解决了漏点，但宽激光中心仍可能随材质和视角产生系统偏移。
4. 相机并非定焦，焦距或对焦变化会使内参和激光平面失效。
5. 标定板可能不够平整，影响激光平面三维点的真实性。
6. 当前导轨轨迹 RMS 已改善到约 `0.23 mm`，不再是约 `2.5～3.5 mm` 直径偏差的主要解释。

### 2. 后处理无法修复连续伪表面

金属反光形成的假点具有高密度、连续性和正常邻域统计，SOR 与 DBSCAN 容易将其视为真实表面。继续增强三维滤波会先损伤真实边缘。

因此应优先在成像和激光中心提取阶段解决：

```text
哑光显像
→ 降低曝光和增益
→ 线宽/饱和/双峰质量门控
→ 跨行和跨帧连续性约束
→ 最后再做三维 ROI、SOR 和小簇清理
```

### 3. ICP 和几何补全的使用边界

本周多次实验说明：

- 无真实重叠时，ICP 的高 fitness 不代表物理对应正确。
- 平面/正方体具有强对称性，容易产生错误旋转和平移。
- ICP 不能修复激光平面造成的错误深度、尺度或非刚性形变。
- 平面和棱边约束可用于诊断或明确标记的外观补全，不能替代真实测量数据。

## 四、本周经验总结

1. 标定质量不能只看 RANSAC RMS，还必须检查内点率、留出板面深度误差和标准件绝对尺寸。
2. 激光中心定义属于标定模型的一部分，修改曝光、增益、响应模式或质量门限后，旧激光平面必须作废。
3. 同一目录不能同时进行采集和重建，重建前应校验采集报告、图像数量和 `positions.csv` 行数一致。
4. 轨迹报告通过只能说明单次扫描内部运动稳定，不能排除整批数据具有相同系统偏差。
5. 点云看起来“能拼上”不等于计量正确；正式结果应优先依靠可验证的绝对标定，而不是后处理强行闭合。
6. 标准件验证应同时报告重复性、局部表面残差和绝对尺寸偏差，避免使用单一指标概括系统精度。
7. 多次扫描起止行程不一致时，完整点云球面拟合会受覆盖区域影响；应同时报告共同覆盖区域与完整点云结果。
8. 共同覆盖只能消除评价区域差异，不能修复激光平面导致的绝对尺度误差，也不能替代真实重复采集。

第一阶段验收目标：

```text
直径平均偏差 < 1.0 mm
共同覆盖区域直径样本标准差 <= 0.1 mm
完整点云直径极差 < 0.5 mm
球面残差 RMS < 0.8 mm
球面残差 P95 < 1.5 mm
```

正式统计至少建议完成 `10` 次重复扫描；两次扫描只用于快速排错。

### 优先级三：改善硬件与成像条件

1. 评估更换定焦相机，避免对焦变化破坏内参。
2. 更换高平整度硬质标定板，避免纸板翘曲。
3. 锁紧相机、激光器和支架，建立标定文件与刚性安装状态的版本对应关系。
4. 评估缩窄线激光宽度，并对反光工件使用可清洗哑光显像剂。
5. 若重新标定后仍存在稳定尺寸偏差，继续检查材质偏移、入射角偏移、残余畸变和单激光平面模型适用性。
