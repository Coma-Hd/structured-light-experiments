# 导轨三维重建：问题复盘与修正流程

本文记录 `ceshi/rail` 无板导轨重建调试中出现过的问题、原因与修正方法。  
正确操作步骤见同目录 [`运行流程.md`](运行流程.md)。

---

## 1. 系统约定（先分清）
最开始一直用了标定板，但是这个是错误的，只有标定的时候用标定板，扫描物体建立点云的时候是不用标定板的

| 项目 | 约定 |
|------|------|
| 标定板 | **只**用于内参、激光平面标定；物体扫描时不需要板 |
| 扫描输入 | 图像 + 导轨行程 `positions.csv` |
| 拼合公式 | `P_world = P_cam + (s - s_ref) * axis` |
| 相机坐标 | X 右、Y 下、Z 前（光轴）；与导轨外壳标注不一定同名 |
| 本机姿态（已回正） | 毛毯 / 地面在画面**下方**。画面左↔右 ≈ 相机 X；画面上↔下 ≈ 相机 Y |
| 旧姿态（已废弃） | 曾出现毛毯在画面右侧（约转 90°）；那时左右扫对应画面上→下 ≈ Y。回正后勿再用 |

## 2. 错误与修正一览

### 错误 A：`scan_axis: "col"` 不生效，红点极稀

**现象**  
激光线很亮，红点却只有十几个，连不成线。

**原因**  
代码只识别 `column` / `row`。写成 `col` 时落到 **row** 分支，近水平激光每行只能取很少点。

**修正**  
- `src/laser_center.py`：增加 `col` → `column` 别名  
- 配置写 `scan_axis: "column"`（水平激光）或 `"row"`（竖直线激光）

**验收**  
同帧点数从约几十升到约数百。

---

### 错误 B：把“画面里看见整块侧面”当成“重建了整块侧面”

**现象**  
激光检查图里木块完整可见，点云却是一条窄带 / 碎面。

**原因**  
检查图里的木块是背景；三维只使用**红点**（激光中心）。每帧只有一条激光线，不是整面纹理。

**修正**  
理解数据流：

```text
每帧：一条激光线 → 若干 3D 点
多帧 + 导轨位移 → 拼成面
```

要整面，必须让激光线在目标面上**扫满另一个方向**（竖直线左右扫，或水平线上下扫）。

---

### 错误 C：`rail.axis` 设错 → 尺度爆炸 / 双面 / V 形

**现象**  
- `inspect_raw` 坐标到几十万 mm  
- 或 `cloud_clean` 像两层皮、V 形折面  
- 或扁带、方向与直觉相反  

**原因**  
`axis` 是**相机坐标系**下的单位方向，不是“我觉得的 X/Y”。  
设错时，各帧点被叠到错误方向，同一平面会剪开成厚片/双层。

**本机曾试过的轴与结果（供对照）**

| axis | 典型结果 |
|------|----------|
| `[1,0,0]` | 易沿 X 拉成窄带；需结合真实扫掠方向判断 |
| `[0,0,-1]` | 曾把尺度拉回可读，但未必是真实运动方向 |
| `[0,1,0]` / `[0,-1,0]` | 对应“画面上→下”；若仍双面，先查激光是否斜切 |

**修正流程**  
1. 明确真实扫掠在画面中的方向（上/下/左/右）  
2. 映射到相机轴（注意 90° 旋转）  
3. 只改 `ceshi/rail/config.yaml` 的 `rail.axis`  
4. 重跑 `3_run_core.ps1`（不必重采）  
5. 若整体镜像，把该轴取反（如 `1`↔`-1`）

**本机当前约定（相机已回正，毛毯在画面下方）**  

- 预览里 **左↔右** 扫 → `axis: [±1, 0, 0]`  
- 预览里 **上↔下** 扫 → `axis: [0, ±1, 0]`  

```yaml
rail:
  axis: [1.0, 0.0, 0.0]   # 默认左右扫；上下扫改为 [0.0, 1.0, 0.0]
```

---

### 错误 D：激光斜切表面 → 单帧深度跨度过大 → 看起来像两个面 / 破碎长条

**现象**  
红点仍在木块“一个表面”上，未跨棱；点云仍呈 V / 双层，或 `cloud_clean` 像**一条一条竖直线**拼成很高的长方形，而不是一块密实小平面。

**原因**  
1. 图像上共面 ≠ 三维里正对。斜视/掠射时，一条激光线在相机系里 **Z 可跨二十多厘米**，叠起来就像折面/长条。  
2. 导轨+竖直线激光的正常结果**本来就是平行线切片**；每条线上点太少、中间丢帧多时，看起来“连不成面”。这不是 mesh 算法单独能补上的。

**诊断（看 `inspect_clean_*.png` / `cloud_clean`）**  
- 正常正对木块侧面：Z 跨度应接近木块边长（厘米级，例如 50～100 mm）  
- 异常：Z 跨度 ~200+ mm，而 Y 只有十几 mm（本次实测约 Z=284 mm、Y=17 mm）  
- XY 顶视：沿扫掠方向一串短竖线、中间有空档 → 丢帧/门槛过高  
- 每条线只有几个点 → `score_threshold` 偏高或 ROI 切得太碎  

**修正**  
1. **先改姿态（主因）**：相机更正对目标面；激光在目标面上端正（竖直/水平，不要斜切）  
2. 扫描中只平移一轴，锁死俯仰/偏航  
3. `positions.csv` 只保留激光稳定打在木块上的中间段  
4. 软件侧可降 `gating.min_laser_points`、略降 `score_threshold`，收紧 `roi.z_max`；然后重跑 `2_check_laser` → `3_run_core`  
5. 验收：`cloud_clean` 的 Z 跨度降到厘米级，且 XY 上空档明显减少后再看 mesh  

---

### 错误 E：起止帧激光未稳定打在木块上

**现象**  
点云两端毛刺、游离碎片；起止激光检查图扭曲。

**原因**  
导轨行程两端激光已离开目标面（空景/地毯），仍被写入 `positions.csv` 并重建。

**修正**  
- 采集时：对准目标面再拍，离开即停  
- 或事后删帧：只保留激光在木块上的中间段  
- 本仓库曾备份全表为 `scan/positions_all.csv`，筛选后写入 `scan/positions.csv`

---

### 错误 F：`image_roi` 过宽 / 过窄

**现象**  
- 过宽：吃进地毯或邻面，像两个面  
- 过窄：木块上只有一小段红点  

**修正**  
调 `ceshi/rail/config.yaml` → `laser.image_roi`，改完只重跑：

```powershell
powershell -ExecutionPolicy Bypass -File ceshi/rail/2_check_laser.ps1
```

红点覆盖目标面、尽量不进地毯/棱角后再 `3_run_core.ps1`。

---

### 错误 G：点太少导致最大平面提取失败（旧平面流程）

**现象**  
`点数太少 263 < 300`，无 `largest_face.*`。

**原因**  
三维 `roi` 与摆放不符，`cloud_clean` 被切光。

**修正**  
用 `inspect_raw` 直方图重设 `roi`，降低 `--min-points`，或先关 ROI 再调。

---

### 错误 H：飞点把 inspect 坐标轴撑爆

**现象**  
`inspect_raw_*` 轴到几十万 mm；主簇其实只有分米级。

**原因**  
少量射线近乎平行激光面，交点跑到极远。

**修正**  
- 看结果以 `cloud_clean` / `inspect_clean_*` 为准  
- 打开并收紧三维 `roi`  
- 忽略 raw 的夸张坐标范围  

---

### 错误 I：激光头被碰歪后仍用旧激光平面

**现象**  
深度整体错乱、尺度异常。

**原因**  
相机–激光相对位姿变了，必须重标激光平面；一般**不必**重标内参（未换镜头/分辨率时）。

**修正**  

```powershell
python scripts/capture.py --out data/laser_plane --mode record --cam 0 --width 800 --height 600 --exposure -4 --gain 20
python scripts/2_calibrate_laser_plane.py
```

验收：拟合 RMS ≈ 0.1–0.5 mm。

## 3. 推荐排错顺序（以后照此）

```text
1. 激光检查红点是否在目标面上、是否够密、ROI 是否合适
2. 单帧/无导轨叠合：深度跨度是否正常（是否斜切）
3. 确认只动一轴，rail.axis 与画面扫掠方向一致（含相机旋转）
4. 去掉起止无效帧
5. 看 cloud_clean / inspect_clean（不要被 inspect_raw 误导）
6. 需要单平面时再跑 extract_largest_plane → largest_face.*
```

## 4. 关键文件

| 路径 | 作用 |
|------|------|
| `ceshi/rail/config.yaml` | 激光、ROI、`rail.axis`、三维 ROI |
| `ceshi/rail/scan/positions.csv` | 当前参与重建的行程表 |
| `ceshi/rail/scan/positions_all.csv` | 筛选前备份（若存在） |
| `ceshi/rail/output/cloud_clean.ply` | 质量判断主点云 |
| `ceshi/rail/output/inspect_clean_*.png` | 投影体检 |
| `output/laser_plane.yaml` | 激光平面（碰激光头后重标） |
| `src/laser_center.py` | 激光提取（含 scan_axis 别名） |
| `src/reconstruct.py` | `pose_source=rail\|charuco` |
